# 群星脊梁博物馆 · 3D 虚拟展厅

G10 语文必修上册第二单元「时代脊梁」主题项目 —— 一座纯 HTML 的线上博物馆。

- **3D 可漫游主页**：推门进入、拖拽/WASD 移动、视角旋转，30 个人物展位环绕大厅
- **30 位时代脊梁展厅**：人物档案 / 高光时刻 / 精神密码 / 感动箴言，每人独立配色与意境
- **语音讲解**：微软神经网络语音，31 段音频，像真博物馆一样听讲解
- **小游戏**「脊梁 · 猜一猜」：三种题型 + 计时 + 答对显示照片

## 打开方式

双击 `index.html`（推荐 **Chrome / Edge**），无需联网、无需安装任何软件。

> 需要浏览器支持 WebGL（3D）与播放音频，现代浏览器默认均支持。

## 目录结构

```
index.html            3D 主页（推门进入大厅）
袁隆平.html …         30 位人物展厅
game.html             小游戏
images/               人物肖像 · 背景图 · 馆印
audio/                语音讲解（31 段 mp3）
js/three.min.js       3D 引擎（已本地化）
generate.py           生成脚本（可重跑改文案）
2D/                   最初的 2D 版（保留版本，双击 2D/index.html 打开）
```

## 操作说明

| 操作 | 方式 |
|------|------|
| 进入大厅 | 点「🚪 推门进入」 |
| 转动视角 | 鼠标 / 手指拖拽 |
| 前进后退 | W A S D / 方向键 / 滚轮 |
| 自动漫游 | 点「🚶 自动漫游」 |
| 进入展厅 | 点击墙上的展位（或「📋 名录」） |
